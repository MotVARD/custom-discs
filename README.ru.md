# Custom Discs — NeoForge 1.21.1

Загружай свои аудиофайлы и проигрывай их в проигрывателях Minecraft.

---

## Возможности

- Загрузка `.wav`, `.mp3` или `.ogg` через игровой экран
- 3D звук с затуханием по расстоянию и панорамированием; совместим с Sound Physics Remastered
- Проигрывание начинается во время загрузки — ждать полного файла не нужно
- Все рядом слышат синхронно
- Настраиваемый лимит размера загрузки, общий лимит хранилища, лимит файлов на игрока, кулдаун, права для каждой команды
- Локальный клиентский кэш треков с лимитом размера

---

## С чего начать

1. Установи [NeoForge 21.1.x](https://neoforged.net/) для Minecraft 1.21.1
2. Положи `customdiscs-<версия>.jar` в `mods/`
3. Запусти игру и введи `/disc upload`

---

## Команды

| Команда | Описание | Права по умолчанию |
|---------|----------|--------------------|
| `/disc upload` | Открыть экран загрузки | Все |
| `/disc list` | Список загруженных файлов с размерами и автором | Операторы |
| `/disc delete <filename>` | Удалить загруженный файл | Операторы |

## Конфигурация

`customdiscs-server.toml` — синхронизируется с клиентами, хранится для каждого мира в `<world>/serverconfig/`:

```toml
[network]
  # Лимит размера одной загрузки в байтах.
  maxUploadBytes = 104857600

  # Общий размер папки загрузок в МБ. 0 = без лимита.
  maxTotalStorageMb = 5120

  # Задержка между аудио-чанками при стриминге клиенту.
  chunkSendDelayMs = 10

[audio]
  # Дистанция в блоках, где громкость достигает нуля.
  maxAudibleDistance = 64.0

  # Игроки за пределами этого радиуса не получают пакеты воспроизведения.
  broadcastRadius = 80.0

[privacy]
  # 0 = все, 2 = операторы, 4 = только консоль.
  uploadPermLevel = 0
  listPermLevel   = 2
  deletePermLevel = 2

  # Секунд между загрузками одного игрока. 0 = без кулдауна.
  uploadCooldownSeconds = 30

  # Максимум треков на игрока. 0 = без лимита.
  perPlayerFileLimit = 0
```

`customdiscs-client.toml`:

```toml
[privacy]
  enableMusicDownload = true
  maxCacheSizeMb = 500

[network]
  packetDownloadTimeoutSeconds = 30
```

## Хранение файлов

- Загрузки сервера: `customdiscs_uploads/`
- Кэш клиента: `customdiscs_cache/` (LRU-вытеснение по `maxCacheSizeMb`)
