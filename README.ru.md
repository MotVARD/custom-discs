# Custom Discs - NeoForge 1.21.1

![Minecraft](https://img.shields.io/badge/Minecraft-1.21.1-green)
![NeoForge](https://img.shields.io/badge/NeoForge-21.1.x-orange)
![License](https://img.shields.io/badge/License-MIT-blue)

Загружайте свои аудиофайлы и слушайте их в музыкальных проигрывателях Minecraft.

> [English version](README.md)

---

## Возможности

- Загрузка `.wav`, `.mp3` и `.ogg` прямо из игрового окна
- Объёмный звук; работает вместе с Sound Physics Remastered (ревербация/окклюзия применяются поверх)
- Настраиваемая дальность слышимости (расстояние, на котором диск затихает)
- Музыку одновременно слышат все, кто находится рядом
- Настраиваемые ограничения загрузки, лимит треков на игрока, задержка и права на команды
- Локальный кэш треков на клиенте с ограничением размера

---

## Установка

1. Установите [NeoForge 21.1.x](https://neoforged.net/) для Minecraft 1.21.1
2. Положите `customdiscs-<версия>.jar` в папку `mods/`
3. Запустите игру и введите `/disc upload`

---

## Команды

| Команда | Описание | Права по умолчанию |
|---------|----------|--------------------|
| `/disc upload` | Открыть экран загрузки | Все игроки |
| `/disc list` | Показать загруженные файлы с размером и автором | Операторы |
| `/disc delete <файл>` | Удалить загруженный файл | Операторы |

---

## Настройка

При первом запуске создаются два файла настроек; каждый параметр в них снабжён
поясняющим комментарием:

- `customdiscs-server.toml`: ограничения загрузки, задержка, дальность
  слышимости и права на команды. Синхронизируется с клиентами, хранится
  отдельно для каждого мира.
- `customdiscs-client.toml`: размер локального кэша и возможность отключить
  приём музыки.
